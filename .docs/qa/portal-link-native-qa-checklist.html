포털 계정 P는 첫 연동에 한 번 성공하면 계정 B에 묶인다. 그래서 상태순 보기의 순서(준비물 그대로 → API 호스트 차단 → 계정 B 첫 연동 성공 직후 → 계정 C 로그인 → 포털 호스트 차단 → 웹 재연동 차단 해제 후 → 디버그: 앱 로직만 · 포털 호스트 차단 → 디버그: 서버 로직만)를 지켜 밟는다. 웹 수정이 배포되기 전이면 웹 재연동 묶음은 건너뛴다. 계정을 바꿀 때는 앱 데이터를 지우고 다시 로그인한다. 웹 연동 폼은 지금 PORTAL_LINK_DISABLED = true 라서 현재 포털 연동을 잠시 중단했습니다. 안내를 띄운다. 이 문구가 없으면 네이티브 화면이다.
